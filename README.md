# 🕐 Reloj Premium Web

🌐 **[¡Haz clic aquí para usar el reloj en vivo!](https://michaelarc-ni.github.io/reloj-premium-web/)**

Una aplicación web de gestión del tiempo lista para usar. Cuenta con un diseño moderno, animaciones fluidas y efectos visuales generados con Canvas. No necesitas instalar nada para utilizarla.

## ✨ Características

* **Reloj Digital y Analógico:** Sincronización en tiempo real con fecha completa, número de semana y zona horaria.
* **Alarma Integrada:** Configuración de alarmas con notificaciones visuales y sonoras, incluyendo función de "Posponer" (Snooze).
* **Temporizador:** Cuenta regresiva precisa con alerta sonora al finalizar.
* **Cronómetro:** Medición de tiempo exacta con registro de vueltas (laps) y milisegundos.
* **Modo Claro / Oscuro:** Transición fluida entre temas para adaptarse a tu preferencia.
* **Fondo Interactivo:** Efecto de estrellas animado y fondo con colores dinámicos.
* **Diseño Responsivo:** Funciona perfectamente tanto en tu computadora como en tu teléfono móvil.

## 🚀 Cómo usar este reloj

¡Es muy fácil y tienes dos opciones!

### Opción 1: Usarlo en línea (Recomendado)
Simplemente entra a este enlace desde cualquier navegador en tu celular o computadora y guárdalo en tus favoritos:
👉 **[michaelarc-ni.github.io/reloj-premium-web](https://michaelarc-ni.github.io/reloj-premium-web/)**

### Opción 2: Usarlo sin internet (Descarga directa)
Si quieres tener los archivos en tu computadora para usarlos sin conexión a internet:
1. Ve a la parte superior de esta página y haz clic en el botón verde que dice **"<> Code"**.
2. Selecciona **"Download ZIP"**.
3. Descomprime el archivo descargado en tu computadora.
4. Haz doble clic en el archivo `index.html` y se abrirá en tu navegador web. ¡Listo!
