# 🕐 Reloj Premium Web

Una aplicación web multifuncional de gestión del tiempo con un diseño moderno, animaciones fluidas y efectos visuales generados con Canvas. 

## ✨ Características

*   **Reloj Digital y Analógico:** Sincronización en tiempo real con fecha completa, número de semana y zona horaria.
*   **Alarma Integrada:** Configuración de alarmas con notificaciones visuales y sonoras, incluyendo función de "Posponer" (Snooze).
*   **Temporizador:** Cuenta regresiva precisa con alerta sonora al finalizar.
*   **Cronómetro (60 FPS):** Medición de tiempo de alto rendimiento con registro de vueltas (laps) y milisegundos exactos.
*   **Modo Claro / Oscuro:** Transición fluida entre temas para adaptarse a la preferencia del usuario.
*   **Fondo Interactivo:** Efecto *Starfield* (estrellas) animado y fondo con gradientes dinámicos en segundo plano.
*   **Diseño Responsivo:** Interfaz adaptada para dispositivos móviles y de escritorio.

## 🛠️ Tecnologías Utilizadas

*   **HTML5:** Estructura semántica.
*   **CSS3:** Variables CSS, animaciones (`@keyframes`), diseño adaptable (Flexbox) y optimización de rendimiento (`will-change`).
*   **JavaScript (Vanilla):** Programación orientada a objetos (clases), `requestAnimationFrame` para animaciones a 60 FPS y API de Web Audio (`AudioContext`) para los sonidos.
